Плагин «Tests»: задержка и HTTP-тесты через delay API mihomo, скорость через полосы проверок, рейтинг (`Rate`). Модуль `auto` — Auto select на результатах тестов: обёртка `servers::Select`, резервы через `servers::FAILOVER`, причина через `servers::IDLE`, проверка текущего сервера каждые 10 с.

- Проверка 100+ серверов должна оставаться быстрой без потери качества.
- Экран: тестовые URL и ожидаемый статус; порядок не важен — без стрелок.
- Пока Auto select включён, прокси не должен оставаться без рабочего подключения.
- Отказ входа в цепочке Chain exit — тоже забота Auto select.
- Порядок подписок — приоритет Auto select; обновление подписки без смены порядка его не меняет.
