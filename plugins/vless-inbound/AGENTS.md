VLESS-вход для своего узла. Должен быть максимально незаметным: REALITY self-steal на своём домене, XHTTP вместо raw TCP, браузерный fingerprint, значения из диапазонов, явный XMUX, никакой панели на IP входа.

- Сайт-приманка встроенный, сертификат Let's Encrypt (TLS-ALPN-01 через 443).
- Ссылка для клиента строится одной функцией `link`.
- «Send directly» добавляет в начало Routing правило `inbound:vless` → Direct (VLESS clients): напрямую идут только клиенты, трафик устройства следует своим правилам.
