Дизайн-система egui без домена: токены (`theme.rs`), палитра (`palette.rs`), иконки (`icons.rs`), виджеты (`widgets/`). Плагины не задают свои цвета, отступы и раскладку — всё отсюда.

## Ориентир

Компактная утилита для четверти экрана. Качество — как Linear / Raycast: спокойные нейтральные поверхности, цвет только со смыслом, одинаковое расположение элементов на всех экранах. Размеры проверки — 480 × 540 и 640 × 560 (светлая тема), 1040 × 600 (тёмная, боковая панель закреплена).

## Токены

- Отступы: `SPACE_XS 2`, `SPACE_S 4`, `SPACE_M 8`, `SPACE_L 12`, `SPACE_XL 16`; поле страницы `PADDING 10`, отступ строк и карточек `INSET 10`.
- Высоты: контрол `CONTROL 26`, строка `ROW 34`, двухстрочная 44, статус-бар 34, навигация 48.
- Радиусы: карточки, поповеры, тосты `RADIUS 8`; кнопки, поля, строки `RADIUS_CONTROL 6`; теги 4.
- Шрифт Ubuntu: `BODY 13`, `SMALL 12` (вторая строка, счётчики), `CAPTION 11` (подписи колонок), `TITLE 15` bold. Числа — тем же пропорциональным шрифтом, по правому краю колонки; моноширинного текста нет.
- Колонка подписей `LABEL_WIDTH 96` — общая для всех списков свойств.
- Палитра — роли, одинаковые для обеих тем: `background`, `surface`, `hover`, `subtle`, текст `foreground` > `muted` > `faint`, `border`, `control_border`, `accent`, `action_*`, статусы `success`/`warning`/`danger`. Текст и бейджи красит только `Tone` (Neutral, Accent, Success, Warning, Danger). `palette.tag(hue)` — восемь цветов тегов с контрастом ≥ 4.5:1.

## Иконки

Шрифт Phosphor (regular и fill, `assets/fonts/Phosphor*.ttf`); `Icon` сопоставляет имя с кодовой точкой, `Icon::Custom` — для плагинов. Размер 16, на кнопках строк 14–16, в навигации 18. Смысл закреплён: `Connected` — подключено; `Disconnect` — разорванная ссылка; `Delete` — корзина; `Edit` — карандаш; `Up`/`Down` — порядок; `Refresh`, `Checks` (спидометр), `Filter`, `Auto` (волшебная палочка), `Listeners` (вилки), `Lock`/`Unlock`.

## Анатомия страницы

1. `page_header(title, counter, actions)` — заголовок и приглушённый счётчик слева («84 servers · 1 excluded»), действия справа; при нехватке места скрывается счётчик.
2. `add_bar` (или `ListEditor::add_form`) — поля и основная кнопка «+ Add» в одну строку над списком; `Fields::new(width)` считает ширины.
3. `list_card` / `card` — подписи колонок (`list_header`), строки (`row`) с прокруткой внутри карточки. Пустой список — иконка, заголовок и следующий шаг внутри карточки.
4. Сортировка и фильтры таблицы — только в заголовках колонок: `sort_caption` (клик сортирует, повторный — обратно, стрелка у активной; состояние — `Sort<K>`), `filter_button` (воронка с числом активных фильтров, меню из `filter_group` / `filter_option`). Отдельных селектов над списком нет.

## Строки

- 34 pt, со второй строкой 44 pt; наведение — заливка `hover`, выбранная — мягкая акцентная.
- Действия строки (порядок, карандаш, корзина) бледные в покое, полные при наведении на строку; корзина краснеет только под указателем. Удаление — одним нажатием.
- Вторая строка (`subtitle`) — 12 pt в тоне статуса: «Updated 2 h ago» (muted), «Refresh failed · причина · last loaded 2 h ago» (warning), «Loading…».
- Фоновая работа видна в строке: спиннер у загружаемого объекта; кнопка задачи становится «Stop 12/82» с полосой прогресса.
- **Телефон (уже 480 pt) — без кода в плагинах**: кнопка с иконкой показывает только иконку (текст в подсказке), `tag` становится точкой, `action_cell` сжимается до одной кнопки, фиксированные колонки `ListEditor` уходят на вторую строку. Плагин не проверяет размер экрана.

## Компоненты

| Компонент | Использование |
|---|---|
| `Button::primary` | одно главное действие вида: Add, Save, Restart now |
| `Button::secondary` | остальные действия; `.selected()` — открытый редактор; `.count()` — счётчик в кнопке |
| `Button::ghost` | ссылки-действия: Manage, Open Subscriptions, Retry |
| `Button::danger` | подтверждение разрушительного действия (замена настроек) |
| `icon_button(_ex)` | 26 × 26, всегда с подсказкой и доступным именем |
| `toggle`, `select`, `choice`, `segmented` | переключатель с подписью; выпадающие списки фиксированной ширины; сегменты |
| `card`, `settings_card`, `settings_row`, `settings_item` | подпись слева, контрол справа, разделители; в узком окне контрол уходит под подпись |
| `badge(text, tone)`, `tag(text, hue)`, `tag_dot` | тип, протокол, Restart required; цвет источника |
| `property`, `property_with`, `disclosure` | детали с общей колонкой подписей, копирование по наведению, редкие поля под «More details» |
| `stats`, `banner(tone, text, action)` | метрики в карточке подключения; полоса предупреждения |

Счётчики — `plural` / `count`; состояния с заглавной буквы (Running, Done, Failed).

## Текст и подсказки

- В интерфейсе нет текста-подсказок: ни поясняющих абзацев, ни постоянных описаний, ни подсказок под полями. Видимы названия, значения, счётчики, состояние и ошибки. Предупреждение о последствиях — рядом с подтверждаемым действием.
- Подсказка — только тултип, и он помогает, а не дублирует экран: не повторяет видимую подпись, значение или состояние. Полное значение по наведению — только если текст обрезан. Сложным функциям — краткая подсказка с неочевидными условиями и последствиями.

## Проверка

Реальный браузер, обе темы, 480 × 540, 640 × 560, 1040 × 600; длинные имена, раскрытые детали, ошибки, удаление строк, поповер панелей, тосты, прокрутка колесом.
