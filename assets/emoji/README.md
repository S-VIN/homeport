The 32-pixel tiles are rendered from Google's Noto Color Emoji (Fedora package google-noto-color-emoji-fonts-20260921). The source font is licensed under the SIL Open Font License; see OFL.txt. Tile order follows the 3,953 fully qualified sequences and components in Unicode Emoji 17.0 emoji-test.txt. Unicode's data license is included. Each row of the atlas has 64 tiles, with a one-pixel transparent gutter inside each tile.
